# LGTV Add Homebrew Repo
A small shell script to streamline the process of adding a repo to the LG TV homebrew appstore. 

## Instructions
* SSH into your LGTV
* Download the script: `wget https://github.com/HeyItsJono/LGTV-Add-Homebrew-Repo/raw/refs/heads/main/add_repo.sh`
* Make the script executable: `chmod +x add_repo.sh`
* Run the script: `./add_repo.sh repo-url-here`
* Your TV will automatically open the HB store, and bring up the prompt to add the repo, with the URL already filled in
* Click OK on the TV to add the repo
